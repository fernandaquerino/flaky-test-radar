# Flaky Test Radar

Self-hosted Playwright flakiness analytics for developers and small teams.

Node.js 24, pnpm, strict TypeScript, NestJS, Next.js, PostgreSQL, Prisma and BullMQ.

## Development

Use Node.js 24, then `corepack enable`, `pnpm install` and `pnpm check`.

## Status

Phase 1 implementation in progress. See [the specification](docs/SPEC.md). The roadmap will be documented in step 10.
